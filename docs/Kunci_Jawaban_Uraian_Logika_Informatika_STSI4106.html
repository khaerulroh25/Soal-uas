Soal 1: Sintaks Logika Proposisional & Interpretasi

Skor: 25
a. Buatlah suatu kalimat dalam bahasa logika proposisional yang mengandung simbol kebenaran true, simbol proposisional P, Q, dan R, serta penghubung proposisional: not, and, or, dan if then else.

b. Diketahui kalimat ℱ berikut ini:
ℱ : If (P and (Q or not Q)) then (not R) else (if (P and R) then (R or Q))
Selidiki apakah interpretasi I = {R ← false, Q ← true, P ← false, S ← true} merupakan interpretasi untuk kalimat ℱ.
💡 Jembatan Keledai & Kunci Hafalan:
• Definisi Interpretasi untuk ℱ: Interpretasi I adalah interpretasi untuk kalimat ℱ jika dan hanya jika I memberikan nilai kebenaran kepada SEMUA simbol proposisi yang muncul di dalam ℱ (adanya simbol ekstra di I tetap diperbolehkan).
✓ JAWABAN RESMI & TERUJI

Penyelesaian Bagian a:

Kalimat logika proposisional yang valid dan memenuhi semua syarat yang diminta:

if (P and not Q) then (R or true) else (Q and not R)
  • Simbol kebenaran: true ✓
  • Simbol proposisi: P, Q, R ✓
  • Penghubung: not, and, or, if then else ✓

Penyelesaian Bagian b:

  1. Himpunan simbol proposisi yang muncul dalam kalimat ℱ adalah:
    Prop(ℱ) = { P, Q, R } (simbol S tidak terdapat di dalam kalimat ℱ).
  2. Interpretasi yang diberikan adalah:
    I = { R ← false, Q ← true, P ← false, S ← true }
  3. Domain simbol proposisi pada interpretasi I adalah:
    Domain(I) = { P, Q, R, S }
  4. Berdasarkan definisi modul Logika Informatika:
    Sebuah interpretasi I dikatakan sebagai interpretasi untuk kalimat ℱ jika I menetapkan nilai kebenaran (true atau false) kepada setiap simbol proposisi yang terdapat dalam ℱ, yaitu Prop(ℱ) ⊆ Domain(I).

Kesimpulan:
Karena semua simbol dalam ℱ (yaitu P, Q, dan R) telah diberi nilai kebenaran oleh I, maka interpretasi I MERUPAKAN interpretasi untuk kalimat ℱ (simbol S di dalam I merupakan simbol bebas/ekstra yang tidak mempengaruhi status interpretasi).

Soal 2: Pohon Keputusan (Decision Tree)

Skor: 25
Diketahui suatu kalimat logika proposisional:
ℱ : (if S then not(Q or R) else not P) if and only if (not(Q or R) and P)
Bangun pohon keputusan untuk kalimat ℱ.
💡 Jembatan Keledai & Kunci Hafalan:
• Pohon keputusan mencabangkan nilai tiap proposisi (kiri = true, kanan = false) secara bertingkat.
• Perhatikan bahwa (not(Q or R) and P) hanya bernilai true jika P = true, Q = false, R = false. Pada kasus lainnya bernilai false.
✓ JAWABAN RESMI & TERUJI

Simbol proposisi yang terlibat: S, P, Q, R (ada 4 proposisi, total 16 kemungkinan daun nilai kebenaran).

Mari kita sederhanakan subkalimat ℱ:
Misalkan A = not(Q or R). Maka A = true hanya jika Q = false dan R = false.
Ruas kiri: LK = if S then A else not P.
Ruas kanan: RK = A and P.
Kalimat ℱ: LK ≡ RK (bernilai true jika nilai kebenaran LK sama dengan RK).

Struktur Pohon Keputusan:

[ S ] / \ true / \ false / \ [ P ] [ P ] / \ / \ T F T F / \ / \ / \ / \ [Q] [Q] [Q] [Q][Q] [Q][Q] [Q] / \ / \ / \ / \/ \ / \/ \ / \ [R] ... (cabang daun ke R)

Tabel Evaluasi Nilai Daun (Terminal Nodes):

SPQRA = not(Q or R)Ruas Kiri (LK)Ruas Kanan (RK)Nilai Akhir ℱ
TTT*FFFtrue
TTFTFFFtrue
TTFFTTTtrue
TF**F / TF / TFtrue (jika A=F) / false (jika A=T)
FT***not P = FA and Ptrue (jika A=F) / false (jika A=T)
FF***not P = TFfalse

Pohon Keputusan Lengkap (Representasi Cabang):

• S = true
  ├─ P = true
  │   ├─ Q = true  ➔ (R=true ➔ true,  R=false ➔ true)
  │   └─ Q = false ➔ (R=true ➔ true,  R=false ➔ true)
  └─ P = false
      ├─ Q = true  ➔ (R=true ➔ true,  R=false ➔ true)
      └─ Q = false ➔ (R=true ➔ true,  R=false ➔ false)

• S = false
  ├─ P = true
  │   ├─ Q = true  ➔ (R=true ➔ true,  R=false ➔ true)
  │   └─ Q = false ➔ (R=true ➔ true,  R=false ➔ false)
  └─ P = false
      ├─ Q = true  ➔ (R=true ➔ false, R=false ➔ false)
      └─ Q = false ➔ (R=true ➔ false, R=false ➔ false)

Soal 3: Substitusi Total (Total Substitution)

Skor: 25
Diketahui suatu kalimat logika proposisional:
ℱ : (Q and R) if and only if (P and (if Q then R))
Tentukan kalimat hasil substitusi:
ℱ ◁ { (Q or R) ← (P and Q), R ← (Q or S), (P or R) ← S }
💡 Jembatan Keledai & Kunci Hafalan:
• Notasi ℱ ◁ { S₁ ← T₁, S₂ ← T₂, ... } artinya substitusi serempak (simultaneous replacement).
• Cari kemunculan subkalimat Sᵢ di dalam ℱ secara tepat. Jika tidak muncul dalam ℱ, aturan tersebut diabaikan!
• Di sini yang muncul di ℱ hanya atom R. Subkalimat (Q or R) dan (P or R) TIDAK ADA di dalam ℱ!
✓ JAWABAN RESMI & TERUJI

Langkah Analisis Subkalimat:

  1. Subkalimat target substitusi:
    • Target 1: (Q or R) ➔ Tidak ada dalam ℱ (dalam ℱ adalah Q and R).
    • Target 2: R ➔ Ada dalam ℱ (muncul 2 kali: di Q and R dan di if Q then R).
    • Target 3: (P or R) ➔ Tidak ada dalam ℱ.
  2. Oleh karena itu, setiap kemunculan simbol R digantikan oleh (Q or S):
    • Bagian (Q and R) menjadi (Q and (Q or S))
    • Bagian (if Q then R) menjadi (if Q then (Q or S))

Hasil Akhir Kalimat Substitusi:

(Q and (Q or S)) if and only if (P and (if Q then (Q or S)))

Soal 1: Sintaks Logika Proposisional & Interpretasi

Skor: 25
a. Buatlah suatu kalimat dalam bahasa logika proposisional yang mengandung simbol kebenaran false, simbol proposisional P, Q, dan R, serta penghubung proposisional: and, or, if then else, dan if and only if.

b. Diketahui kalimat ℱ berikut ini:
ℱ : If (P and (Q or not Q)) then (R and S) else (if P then (R or Q))
Selidiki apakah interpretasi I = {R ← false, Q ← true, P ← false} merupakan interpretasi untuk kalimat ℱ.
💡 Jembatan Keledai & Kunci Hafalan:
• Di Paket 2b, perhatikan simbol proposisi pada ℱ: ada S! Apakah I memiliki nilai untuk S? TIDAK ADA.
• Jadi I BUKAN interpretasi untuk ℱ karena tidak lengkap!
✓ JAWABAN RESMI & TERUJI

Penyelesaian Bagian a:

Contoh kalimat proposisional yang memenuhi semua syarat:

(if (P and Q) then (R or false) else P) if and only if (Q or R)
  • Simbol kebenaran: false ✓
  • Simbol proposisi: P, Q, R ✓
  • Penghubung: and, or, if then else, if and only if ✓

Penyelesaian Bagian b:

  1. Himpunan simbol proposisi yang muncul di dalam kalimat ℱ:
    Prop(ℱ) = { P, Q, R, S } (simbol S muncul pada subkalimat (R and S)).
  2. Interpretasi yang diberikan adalah:
    I = { R ← false, Q ← true, P ← false }
  3. Domain simbol dari interpretasi I adalah:
    Domain(I) = { P, Q, R }
  4. Berdasarkan definisi:
    Interpretasi untuk kalimat ℱ harus memberikan nilai kebenaran kepada setiap simbol proposisi yang ada di dalam ℱ.

Kesimpulan:
Karena simbol proposisi S ∈ Prop(ℱ) tetapi S ∉ Domain(I) (simbol S tidak diberi nilai kebenaran oleh I), maka interpretasi I BUKAN merupakan interpretasi untuk kalimat ℱ.

Soal 2: Pohon Semantik (Semantic Tree) & Sifat Kalimat

Skor: 25
Diketahui suatu kalimat logika proposisional:
ℰ : if P then (R or Q) else not P
Buatlah pohon semantik untuk kalimat ℰ serta tentukan sifat kalimat yang mungkin untuk kalimat ℰ.
💡 Jembatan Keledai & Kunci Hafalan:
• Tautologi (Valid): Semua cabang bernilai true.
• Kontradiksi (Inconsistent/Unsatisfiable): Semua cabang bernilai false.
• Contingent (Falsifiable & Satisfiable): Ada cabang yang bernilai true dan ada yang bernilai false.
✓ JAWABAN RESMI & TERUJI

Analisis Nilai Kalimat:

  • Jika P = false: Kalimat menjadi not P = not(false) = true (langsung true tanpa bergantung pada Q dan R!).
  • Jika P = true: Kalimat bernilai (R or Q).
    • Jika Q = true atau R = true ➔ true
    • Jika Q = false dan R = false ➔ false

Pohon Semantik (Semantic Tree):

[ Root: ℰ ] / \ P=true / \ P=false / \ [ ℰ: R or Q ] [ ℰ: not(false) ] / \ | Q=true/ \Q=false ( TRUE ) / \ ( TRUE ) [ ℰ: R ] / \ R=true/ \R=false / \ ( TRUE ) ( FALSE )

Sifat Kalimat untuk ℰ:

  1. Satisfiable (Dapat dipenuhi): Terdapat interpretasi yang membuat ℰ bernilai true (misal saat P = false).
  2. Falsifiable (Dapat disalahkan): Terdapat interpretasi yang membuat ℰ bernilai false (yaitu saat P = true, Q = false, R = false).
  3. Contingent: Karena kalimat ℰ tidak selalu true (bukan tautologi) dan tidak selalu false (bukan kontradiksi), maka sifat kalimat ℰ adalah Contingent.

Soal 3: Substitusi Total

Skor: 25
Diketahui suatu kalimat logika proposisional:
ℱ : (Q and P) if and only if (P and (if Q then R))
Tentukan kalimat hasil substitusi:
ℱ ◁ { Q ← (P and Q), (R or Q) ← (Q or S), (P or R) ← S }
💡 Jembatan Keledai & Kunci Hafalan:
• Di dalam ℱ: proposisi Q muncul 2 kali (pada Q and P dan pada if Q then R).
• Subkalimat (R or Q) dan (P or R) tidak ada dalam ℱ, sehingga tidak diterapkan.
✓ JAWABAN RESMI & TERUJI

Langkah Substitusi:

  1. Daftar aturan substitusi:
    • Q ← (P and Q) ➔ Diterapkan ke setiap kemunculan atom Q.
    • (R or Q) ← (Q or S) ➔ Tidak ditemukan di ℱ (diabaikan).
    • (P or R) ← S ➔ Tidak ditemukan di ℱ (diabaikan).
  2. Substitusi pada masing-masing bagian:
    • Ruas kiri: (Q and P) menjadi ((P and Q) and P)
    • Ruas kanan: (if Q then R) menjadi (if (P and Q) then R)

Hasil Akhir Kalimat Substitusi:

((P and Q) and P) if and only if (P and (if (P and Q) then R))
